# Team workflow

1. One person creates the GitHub repository and pushes the starter project.
2. Invite all three teammates as collaborators.
3. Protect `main` if repository settings permit.
4. Each member works on a separate feature branch.
5. Pull before starting work; push commits frequently.
6. Merge through pull requests after another member reviews.
7. Do not edit the same template/controller simultaneously without coordinating.

Suggested ownership:
- Member 1: subscription lifecycle and quotation workflow
- Member 2: products, variants, plans, discounts and tax rules
- Member 3: invoice, payment and billing automation
- Member 4: shared UI, dashboard, customer portal and responsive testing
